## Features

`pygame-foundation` provides a collection of systems for building and organizing Pygame applications:

- **Entities** — Objects that represent things in your game.
- **Worlds** — Manage and organize entities.
- **Scenes** — Organize different parts or states of your game.
- **Input Management** — Handle keyboard and mouse input.
- **Camera System** — Manage the game's view of the world.
- **Asset Management** — Manage game assets.
- **Collision Checks** — Handle collisions between entities.
- **Timers** — Execute actions after a delay or at intervals.
- **Debugging & Logging** — Help debug and monitor your application.
- **Game Class** — Provides the main structure for a Pygame application.

Explore the [Guides](guides/game.md) to learn more about each system.
