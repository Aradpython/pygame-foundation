# **Installation**
`pygame-foundation` can simply be installed by running the following command:
```bash
pip install pygame-foundation
```
If the command above doesn't work, then you may attempt using the following command:
```bash
python -m pip install pygame-foundation
```

If none of the above are run successfully, attempt downloading the source code from github or PyPI:
[github]: https://github.com/Aradpython/pygame-foundation
[pypi]: https://pypi.org/project/pygame-foundation/#files
 - [Github]
 - [PyPI]

**IMPORTANT**: If you are manually installing the package, remember that `pygame-foundation` uses `pygame-ce` and `termcolor`. Please install the dependencies accordingly as well.
